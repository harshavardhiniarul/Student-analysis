# Student Pass/Fail Prediction

This project uses a **Neural Network built from scratch using NumPy** to predict whether a student will **Pass or Fail**.

## Features

The model uses:

* Study Hours
* Attendance
* Previous Marks
* Assignment Scores

## Technologies

* Python
* NumPy
* Pandas
* Matplotlib

## Neural Network

The model includes:

* Weight and bias initialization
* Forward propagation
* ReLU activation
* Sigmoid activation
* Loss calculation
* Backpropagation
* Gradient descent
* Model training
* Pass/Fail prediction

## Output

The model provides:

* Training loss
* Training accuracy
* Testing accuracy
* Prediction for a new student

A training-loss graph is also generated.

## How to Run

Install the required libraries:

```bash
pip install numpy pandas matplotlib
```

Run the program:

```bash
python neural_network.py
```

The program will train the neural network and predict whether a new student is likely to **Pass or Fail**.

## Restrictions

The project does not use TensorFlow, PyTorch, Keras, or Scikit-learn's neural-network implementation.
